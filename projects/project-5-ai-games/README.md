# Project 5 — AI Games

A game-focused Flask project exploring computer opponents, hints, commentary, score tracking, and resilient fallbacks.

## What it demonstrates

- Game-state management
- Computer move selection
- Session-based state
- Structured output validation
- Commentary/hint generation patterns
- Fallback logic so the game still works without an AI response

The public portfolio demo is a fully playable browser version of Tic-Tac-Toe, while the source below shows the core game logic in Python.
