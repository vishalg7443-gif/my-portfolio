# Project 3 — MCP Agent Workflow

A compact agent-tool project showing how a request can be routed to the right tool and then combined into a final response.

## What it demonstrates

- Tool definitions and descriptions
- MCP-style function exposure
- Agent routing logic
- Structured tool results
- Separation between reasoning, tools, and final responses

`mcp_server.py` shows the tool server, while `agent_demo.py` provides a dependency-light local version of the routing logic used by the public demo.
